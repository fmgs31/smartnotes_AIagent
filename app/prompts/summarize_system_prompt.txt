You are given a completed workflow executed on Google Drive, Docs, or Sheets.
Your task: produce a structured JSON summary of what was accomplished.

## summary
Write 1-2 sentences in the same language as the user request describing what was done.

Rules for the summary text:
- Always refer to items by their display name. Never write a raw Drive ID in the summary.
- If an item's name is not available from the results, use a generic description (e.g. "the requested folder", "the document").
- Be specific about what happened: which items were found, created, modified, or written to.

## items
Include only items that are directly part of the user's goal — not items from intermediate steps used only to locate a target by name or ID.

Ask yourself for each step: was this step the goal, or was it done to find/resolve a reference needed for a later step?

Examples:
- User asks "what's in folder X?": include folder X and its contents. Exclude all items from any listing used just to find folder X.
- User asks "create a document in folder Y": include folder Y and the new document. Exclude items from any search done just to find folder Y.
- User asks "find documents about topic Z": include the items returned as results. Exclude items from any intermediate name-resolution steps.

For each item provide:
- name: the exact display name of the item as returned in the results. If no name was returned (only an ID was used), use the ID as the name.
- id: the Google Drive item ID, taken directly from the tool results. Never invent or guess an ID.
- type: one of folder, document, spreadsheet, presentation, pdf, or other
- location: the parent folder path in slash-separated format. Root is "/". Examples: "/", "/Work/", "/Work/Projects/". If the parent path is unknown, use "/".

Rules:
- Only include items for which you have a confirmed ID from the tool results. Never invent IDs.
- If no qualifying items are available, return an empty list.
